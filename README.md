# 同學各位找個位 — 觸控操作版

[使用網站](https://hcwwwwaiii.github.io/seating-plan-tool/)

以 [Sam Li 原版工具](https://seating-plan-tool-wslisam.pages.dev/) 的公開前端還原版本為基礎。

- 點學生再點另一座位，交換或移到空位；觸控可長按約半秒再拖曳，顯示可放置／不可放置落點，未長按直接滑動仍可捲頁；電腦仍可拖曳。
- 觸控座位選單可鎖定、禁用及取消選取。
- 表格名單可編輯學生及勾選視力照顧、高個子。
- 每個方案可復原及重做最多 30 次操作，新操作會清除重做紀錄，重新整理後操作紀錄清除。Ctrl／⌘ + Z 復原，Ctrl／⌘ + Shift + Z 重做。
- 支援多方案、編排規則、PNG 匯出及 TXT 匯入匯出。

資料只保存在目前瀏覽器的 localStorage，沒有上傳學生名單。不同裝置或網址不會自動同步；請用 TXT 匯出／匯入轉移資料。

## 發布

純靜態網站，index.html 和 app.js 置於同一資料夾。GitHub Pages 由 gh-pages 分支的根目錄發布，無需安裝套件或建置。

JavaScript 語法及桌面瀏覽器的觸控尺寸操作檢查通過；尚未在實體 iPad／Safari 上測試。
## 規則檢查與列印

編排、換位、復原及更改照顧規則後，即時列出視力照顧未坐前兩行、高個子未坐後兩行，以及鎖定／禁用座位的限制。同時勾選兩項並啟用視力照顧規則時，以視力照顧優先。

右側「列印座位表」可列印／另存一頁 A4 橫向 PDF。預設隱藏性別及特徵，兩者可分別勾選顯示。瀏覽器列印預覽請選 A4 橫向並關閉頁首及頁尾。密集行列的文字會縮小。
